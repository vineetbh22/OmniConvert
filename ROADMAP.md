# OmniConvert Roadmap

This roadmap describes the planned direction of OmniConvert. Items may move between releases based on community feedback, maintenance priorities, and implementation complexity.

## Project Goals

OmniConvert aims to be:

- Fast
- Reliable
- Extensible
- Cross-platform
- Automation-friendly
- Raspberry Pi compatible

---

## Current Focus (0.x)

The current phase focuses on building a stable foundation.

### Core Priorities

- Improve converter reliability
- Standardize error handling
- Expand automated test coverage
- Improve logging and diagnostics
- Establish contributor workflows

### Planned

- [ ] Unified conversion result model
- [ ] Structured exception hierarchy
- [ ] Better format validation
- [ ] Improved CLI help and error messages
- [ ] Conversion performance metrics

## Guiding Principles

New features should improve one or more of:

1. Reliability
2. Performance
3. Developer experience
4. Extensibility
5. Usability

Features that significantly increase maintenance burden may be deferred even if technically feasible.
